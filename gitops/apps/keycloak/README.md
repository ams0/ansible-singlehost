# Keycloak

Open-source Identity and Access Management (IAM) solution by Red Hat. Provides Single Sign-On (SSO), OAuth2, OpenID Connect (OIDC), SAML, and user federation.

## Resources

- `namespace.yaml` - Namespace definition
- `keycloak-ocirepo.yaml` - OCI chart repository source
- `keycloak-database-helmrelease.yaml` - CNPG PostgreSQL 18 cluster
- `keycloak-pvc.yaml` - 10Gi PVC (local-path) for custom themes
- `keycloak-helmrelease.yaml` - Flux HelmRelease (app)
- `keycloak-httproute.yaml` - Gateway API HTTPRoute

## HelmRelease Values

| Key | Value | Notes |
|-----|-------|-------|
| `command` | `start` | Runs in production mode |
| `KC_HOSTNAME` | `https://auth.vps.kubespaces.cloud` | Public-facing URL |
| `KC_HOSTNAME_STRICT` | `false` | Allows requests from other hostnames |
| `KC_DB` | `postgres` | Database vendor |
| `KC_DB_URL_HOST` | `keycloak-keycloak-database-cluster-rw` | CNPG read-write service |
| `KC_DB_URL_PORT` | `5432` | Standard PostgreSQL port |
| `KC_DB_PASSWORD` | from CNPG secret | Auto-generated by CNPG operator |
| Bootstrap admin | from `keycloak-bootstrap-admin` secret | Initial admin credentials |
| SMTP | `smtp-relay.gmail.com:587` | STARTTLS, credentials from `keycloak-smtp` secret |

## Database

**CNPG PostgreSQL 18** (`keycloak-database`) - standalone, 1 instance.

Keycloak requires PostgreSQL to store realms, clients, users, roles, sessions, events, and federation configurations. IAM data is security-critical and must survive pod restarts.

## Storage

**PVC: 10Gi local-path** (`keycloak-pvc`) mounted at `/opt/keycloak/themes`.

Stores custom Keycloak themes for branded login pages, registration forms, and email templates.

## Routing

| Hostname | Route |
