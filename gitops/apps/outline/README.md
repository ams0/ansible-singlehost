# Outline

Beautiful team wiki and knowledge base, serving as a self-hosted alternative to Notion and Confluence. Features real-time collaborative editing, search, and document collections.

## Resources

- `namespace.yaml` - Namespace definition
- `outline-pvc.yaml` - 5Gi PVC (local-path) for file uploads
- `outline-database-helmrelease.yaml` - CNPG PostgreSQL 18 cluster
- `outline-helmrepo.yaml` - Helm chart repository source
- `outline-helmrelease.yaml` - Flux HelmRelease (app)
- `outline-httproute.yaml` - Gateway API HTTPRoute

## HelmRelease Values

| Key | Value | Notes |
|-----|-------|-------|
| PostgreSQL host | `outline-outline-database-cluster-rw` | CNPG read-write service |
| PostgreSQL credentials | from CNPG-managed secret | Auto-generated by operator |
| Redis | enabled, standalone architecture | In-chart with persistence |
| File storage | local mode with PVC | Not S3 |
| SMTP | `smtp-relay.gmail.com:587` | For notifications, invites, and sharing emails |
| SMTP credentials | from Kubernetes secret | Gmail app password |
| URL | `https://outline.vps.kubespaces.cloud` | Public-facing URL |

## Database

**CNPG PostgreSQL 18** (`outline-database`) - standalone, 1 instance.

Outline stores documents, collections, users, search indices, and revision history in PostgreSQL. Rich text documents with real-time collaboration, full-text search, and version tracking require a relational database.

## Redis

An in-chart Redis instance (standalone architecture, with persistence enabled) handles caching, real-time collaboration state via WebSockets, and background job processing such as search indexing and email delivery.

## Storage

**PVC: 5Gi local-path** (`outline-pvc`)

Stores uploaded images, file attachments, and document exports. Outline lets users embed images and attach files to wiki pages, all of which are stored on this volume.
